# 雪梨智学 · AI伴学 HTML 交互版本 V4

下载 `xueli-product-demo-v4.zip`，解压后用 Chrome 或 Edge 打开 **雪梨智学-AI伴学交互Demo.html**。图片和代码全部嵌入，不需要服务器或依赖。

本版按最新提供的原图和逐项交互说明实现。原图确定背景、人物、内容框、图标与按钮位置；HTML 在这些区域里支持连续回答、反馈、重试、逐条对话、掌握状态更新与报告生成。正常课程只展示代表性的“爱干净”图片学习。

## 怎么操作

- **欢迎**：尝试自动播报“你好呀，我是雪梨老师，今天我会陪你一起学英语，让我们开始今天的学习吧。”播报结束进入课程。若浏览器首次打开静音，点击原图中的雪梨老师或“开始今天的学习”，启用声音。设备仍未能播报时可以文字方式继续，不会卡住学习。
- **课程**：点击右侧句子或喇叭听朗读；右下角麦克风可问 clean 的意思、当前句子的意思，也可模拟跟读。图片与词句已换成爱干净主题，外围 UI 保留。
- **错误汇总**：沿用单词、句子、练习统计三行布局。初始载入七条示例学习记录（四项已掌握、三项待补练），用于演示错误发现。本次回答会更新这些结果。
- **针对性补练**：左侧目标图与词卡，右侧具体反馈与星级，支持再听、提示和麦克风再次回答。独立通过后更新状态；最多尝试两次，仍失败则降级跟读并保留待巩固。
- **深度引导**：老师的问题先出现并播报；等待孩子回答；孩子气泡先出现；短暂间隔后老师反馈才出现并播报；相关的词组图片卡随后出现。同一绘本只进行一次引导。点击麦克风可选择或输入回答，相关、跑题、表达不完整均有不同处理，最多三轮后收束。
- **总结**：保留原有统计栏、左右反馈区、头像鼓励与按钮结构。内容由示例记录和本次交互共同生成。模块和整次报告自动存入本地家长中心，并默认发起下载。
- **道别**：进入时自动播报鼓励、下次复习重点和道别。播报结束可点“明天见”，也可通过麦克风回应再见。结束后禁用继续回答。

## 声音、输入与报告

声音使用浏览器的语音合成能力，声音种类与是否能自动播放取决于当前设备；首次可能需要点击老师启用。底部“声音 / 演示说明”可关闭语音或自动下载。

AI 回复、语音识别和评分为本地规则模拟。麦克风打开演示输入区，可以使用预设识别结果或输入孩子的话；不采集录音、不请求真实 AI 接口。正常课程问答最多三轮，补练有重试上限。

家长中心使用当前浏览器的本地存储模拟报告接收，不上传远程服务器。报告明确区分预置学习记录与本次输入。老师朗读不计为孩子开口。重置当前演示时保留已保存报告。

## 素材和代码

- `assets/frames/`：原稿界面，用于保留视觉框架。
- `assets/course-clean.png`、`assets/clean-scenes.png`：爱干净主题课程与练习插图。
- `src/`：交互代码和模板；运行 `python3 src/build.py` 可生成单文件 HTML。
- `previews/`：新版交互状态截图。
- `verification/`：本次云环境中的浏览器验收脚本，路径与端口需按运行环境调整。

逐项对应关系见 `需求对照与验收.md`，实际验证范围见 `验收结果.md`。
