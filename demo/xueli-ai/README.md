# 雪梨智学 · AI伴学 HTML 交互 Demo V5

下载 `xueli-product-demo-v5.zip`，解压后用 Chrome 或 Edge 打开 **雪梨智学-AI伴学交互Demo.html**。图片与代码全部内嵌，可离线打开。

本版保留提供的背景、人物、内容框、导航和按钮位置。交互以绘本 **A Clean Room（干净的房间）** 为主线：读故事 → 完成七道练习 → 查看真实作答 → 针对错题补练 → 一次生活引导 → 模块与今日总结 → 语音道别。

## 演示操作

1. 欢迎界面自动尝试播报用户指定的欢迎语。浏览器首次需要启用声音时，点击雪梨老师或“开始今天的学习”。
2. 课程展示四句爱干净主题课文。点句子听朗读；点麦克风可问当前句子的意思或试读。随后点“开始课堂练习”。
3. 练习包含词义选择、看图理解和句子跟读，共七题。选择题直接点击答案；跟读题点麦克风，选一个识别结果或输入孩子说的话。每题提交后才能进入下一题。
4. 七题结束后，汇总首次正确数和实际错题。点词卡、句子卡或“查看更多”可以看到题目、孩子原答案、正确答案与原因。全对时不生成错题，直接进入生活引导。
5. 有错题时，逐题补练同一难点。词义错题重新选择词义；看图错题重新理解 not clean；跟读错题重新提交完整句子。最多重试两次；仍未通过则由老师示范，保留待巩固状态。
6. 同一绘本只进行一次生活引导：老师提问 → 孩子回答 → 老师反馈 → wash hands 词组卡，各条逐步出现。可以用中文回答，再练习英文；跑题最多三轮后收束。
7. 总结使用本轮记录统计掌握、开口和已解决错题；未通过的难点进入下一次复习计划。报告自动保存到当前浏览器的家长中心，默认发起下载。
8. 离开时自动播报鼓励、与页面一致的明日复习目标和道别。播报后点击“明天见”结束。

## 一条推荐的讲解路线

- 第 1 题 room 故意选“玩具”。
- 第 4 题 not clean 故意选“收拾好的房间”。
- 第 7 题识别结果选 `This room is clean.`，故意漏掉 not。
- 其余四题答对。汇总应显示 **7 题、正确 4 题、错误 3 题**。
- 补练时依次回答“房间”“玩具散落的房间”“This room is not clean.”。看图理解与完整跟读分别验证，解决其中一题不会抹掉另一题。
- 生活问答回答“洗手”，随后说 `wash hands`。本路线最终掌握 7 个知识点，解决 3 道错题；每次回答产生的开口次数按实际输入累计。

## 数据规则

- 初始没有预置掌握结果或错题。只有正式练习实际提交后才有课堂作答记录。
- 每题绑定课文来源、目标、题目 ID、孩子答案、结果与错误原因。原始作答不会被补练覆盖。
- 同一知识点有多个验证任务时，需要各项都通过。例如 not clean 同时验证看图理解和完整表达。
- “解决错题”指原来答错、之后同一道题补练通过。老师带练仍保留待巩固，不能冒充通过。
- 只有模拟孩子说话/输入计为开口；选择答案、听老师朗读、老师示范都不计入。
- 课文试读与正式练习分别保存；试读用于即时辅导，正式练习提供汇总依据。
- 报告区分首次作答与后续补练，可以追溯每条结论。

## 声音、AI 与输入

老师使用浏览器语音合成。部分设备首次需要点击；设备无语音能力时可用文字继续。底部“声音 / 演示说明”可关闭语音和报告自动下载。

AI 回复、语音识别与评分使用本地规则演示。麦克风打开模拟识别输入区，不采集录音、不调用真实 AI 服务；句子评分核对识别文本，不能评估真实口音。家长报告保存在当前浏览器，不发送到远程家长端。

## 源码与验证

源码位于 GitHub 仓库的 `demo/xueli-ai/` 目录。运行 `python3 src/build.py` 生成单文件 `index.html`。`assets/frames/` 保存原稿视觉素材，`src/` 为交互源码，`previews/v5-*.png` 为本版状态截图。

浏览器验证脚本位于 `verification/`，默认访问 `http://127.0.0.1:8025`，可用环境变量 `DEMO_URL` 修改。脚本需要 Playwright 和 Chromium；使用当前云环境中的安装路径。

需求对应和实际验证范围见 `需求对照与验收.md`、`验收结果.md`。
