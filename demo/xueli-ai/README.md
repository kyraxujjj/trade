# 雪梨智学 · AI 伴学完整产品功能示意 Demo

下载 `xueli-demo.zip`，解压后用 Chrome 或 Edge 打开 **雪梨智学-AI伴学完整功能Demo.html**。全部代码和图片已嵌入 HTML，不需要服务器、依赖或 API 密钥。

本版根据《雪梨智学 AI伴学 Demo (1).pdf》的 8 个核心阶段实现。竞品截图只用于课程入口、详情、学习路径、解锁、分页和学习任务之间的流程衔接。内容统一为“爱干净”；视觉沿用 PDF 中的教室、雪梨老师、暖黄色/米白面板与橙黄色主按钮。

## 如何演示

1. 点击“查看今天的课程”，查看详情后开始。雪梨老师欢迎结束，自动进入学习路径。
2. 依次完成“听绘本、学单词、读绘本、练绘本”。下一模块在当前模块完成后解锁。正常课程可以随时点击右下角麦克风，提问或模拟孩子回答。
3. 听绘本点击喇叭播放，跟随句子高亮，再做听后理解题；单词页面查看释义、听发音并判断词义；绘本跟读可模拟正确、漏词或不清晰的表达；练习页面独立选择答案。
4. 可以故意答错 clean 或漏掉 not，观察本轮错误汇总和针对性二次练习。独立通过会更新掌握状态；失败两次后降级跟读，保留待巩固，并继续流程。
5. 深度引导中回答“洗手”或“收玩具”，观察如何连接到 wash hands。说一个无关问题，观察老师如何拉回主题。最多三轮后结束自由对话；引导跟读完成后仍不冒充独立掌握。
6. 查看每个模块的具体总结，继续下一模块。四个模块全部完成后，查看整次总结；已解决的薄弱点不再进入明日计划。
7. 进入离场道别，结束本次学习。结束后不会继续教学或聊天。

“讲解路线”可查看上述流程；“演示设置”可关闭语音、切换讲解节奏或关闭自动下载。全屏按照 2340 × 1080 的横屏比例适配。底部控制条属于讲解工具，进入全屏后隐藏。

## 语音与 AI 的演示方式

- 点击麦克风，使用预设识别结果或输入文字模拟孩子说话。默认不采集或上传录音。
- 老师的朗读调用浏览器语音能力；设备未安装相应声音或不允许播放时，保留文字并继续流程。
- 嘴型是随朗读状态变化的简化动画，不是音素级嘴型同步。
- 上下文问答、主题判断、知识库和评分使用本地规则展示产品意图，未连接真实 LLM、ASR、RAG 或发音测评服务。词句准确性由演示输入判定，不是实际发音质量检测。
- 当前任务问答最多三轮；关闭后再次打开也不会解除上限，进入下一个任务才重置。

## 报告与家长中心

每个模块及整次学习结束时，报告自动保存到当前浏览器的家长中心，并默认发起 HTML 报告下载，展示自动生成和家长端接收的功能。浏览器可能限制多文件自动下载，可在家长中心手动下载 HTML 或 JSON，也可在演示设置中关闭自动下载。

家长中心的同步属于本地功能模拟，**不连接远程服务器**。知识点、开口次数、补强结果和明日计划来自本次交互，不是原图里的固定示例统计。老师朗读次数不计入孩子开口次数。重置当前演示不会删除已完成报告，可以展示再次进入和历史记录。
