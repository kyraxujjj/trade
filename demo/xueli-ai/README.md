# 雪梨智学 · AI伴学 App 交互 Demo V8

下载 `xueli-product-demo-v8.zip`，解压后用 Chrome 或 Edge 打开 **雪梨智学-AI伴学App交互Demo.html**。图片、界面和代码内嵌，可离线使用。

本版保留课堂背景、雪梨 IP 和主要内容框，取消主题/模块锁定与强制道别，不限制每日学习量。

## 自由学习

- 欢迎后，爱干净、美味食物、快乐运动、动物朋友四个主题都可选择。
- 每个主题下，绘本、单词、视频、习题均可直接进入，不需要先完成另一个模块或等到次日。
- 爱干净单词仍是核心 AI 演示：认识词卡 → 理解检查 → 开口检查 → 实际错题 → 对应补练 → 一次主题生活引导 → 学习总结。
- 其余入口提供基础学习交互：绘本逐页共读、单词听读与开口、带字幕和语音的情景动画、理解选择题。情景动画用 HTML 场景播放示意视频产品流程，不是外部视频素材。
- 完成后返回学习地图，可选择其他内容、查看学习收获或再学一遍。重练会建立新一轮记录，旧报告保留。
- 同一份爱干净内容重练时，不重复生活引导，不把上轮口头回答计入新一轮开口数。
- 总结页面提供“继续选择学习内容”和可选的“先休息一下”；休息后也可立即继续。

## 老师和麦克风

点击雪梨老师形象打开当前内容的帮助。爱干净单词保留上下文提问弹窗；其他基础内容提供当前词义、句意和重听。

右下角麦克风用于孩子的跟读、回答和口头选择，不作为课程帮助入口。学习记录仅来自真实页面选择或模拟输入，不预置错题。动画播放时打开帮助或麦克风会暂停播放，防止作答内容和画面错位。

## 进度与报告

- 返回地图或刷新页面，保留当前学习进度；旧版本保存的“已结束”状态不会再限制继续学习。
- 跨日期也可继续保存的进度，无需等到新的一天才能开始下一轮。
- 爱干净单词按本轮统计掌握与开口；绘本浏览/动画观看只记录参与，不当作通过掌握评测。
- 不同主题、模块和重练轮次分别保存记录；未学习的内容不会被计为完成。
- 家长中心可查看并下载报告；自动下载可在底部“声音 / 演示说明”关闭。本地存储保留最近 30 份报告。
- 底部“重新演示”用于清空当前轮进度，历史报告保留。

## 核心 AI 流程推荐演示

在爱干净单词中：room 理解选“玩具”、dirty 看图选“收拾好的房间”、clean 开口选 `clen`；其余通过。回顾显示八次检查、五次正确、三次错误。补练对应回答“房间”“玩具散落的房间”“clean”，生活问答回答“洗手”和 `wash hands`。

同一词的理解和开口分别验证；老师示范不计为孩子开口，不把未通过项变成已掌握。

## 实现与验证边界

老师使用浏览器语音合成；AI 回复、识别和评分为本地规则模拟，不采集录音、不调用真实模型。核心完整 AI 评练流程集中在爱干净单词；其他模块提供基础交互，不宣称具有相同深度的 AI 评测。

源码位于 `src/`，执行 `python3 src/build.py` 生成单文件 `index.html`。验证脚本位于 `verification/`，默认访问 8026 端口，可通过 `DEMO_URL` 调整；需要当前环境的 Playwright / Chromium。
