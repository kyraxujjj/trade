# 雪梨智学 AI 伴学 · 原图交互演示

本演示使用提供的 PDF 中的 8 张界面图，保留原有版式、人物与文案，在原按钮、麦克风和喇叭位置加入交互。正常课程页的积木内容改为“爱干净”主题：A Clean Room。

## 下载与打开

下载本目录中的 `xueli-demo.zip`，解压后用 Chrome 或 Edge 打开 `雪梨智学-原图交互版.html`。全部图片已嵌入 HTML，不需要安装依赖或启动服务器。

也可以在 GitHub 打开 `index.html`，使用文件页面的下载原始文件按钮保存，然后用浏览器打开。

## 演示操作

- 点击画面中的原主按钮，完成 8 页流程。
- 点击麦克风，选择模拟孩子回答；课程问答、二次练习和深度引导均可交互。
- 点击老师或喇叭，调用浏览器语音朗读；是否能发声取决于设备和浏览器的语音支持。
- 底部支持上一页、下一页、重置和全屏；键盘左右键可切换页面。
- 家长中心和学习记录支持预览及下载本次演示的互动记录。

AI 回复、语音输入和发音评分为模拟；原图中的统计数据为演示示例，不代表真实测评。未接入后端或报告上传，也未提供真实嘴型动画。
