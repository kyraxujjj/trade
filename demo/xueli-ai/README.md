# 雪梨智学 · AI伴学 App 交互 Demo V7

下载 `xueli-product-demo-v7.zip`，解压后用 Chrome 或 Edge 打开 **雪梨智学-AI伴学App交互Demo.html**。图片、界面和代码全部内嵌，可离线使用。

本版沿用提供的课堂背景、雪梨 IP、顶部导航和主要内容框，补齐主题选择、四模块地图、返回与继续、学习进度、完成状态以及收尾路径。

本次调整：点击雪梨老师形象打开课程提问弹窗；麦克风用于孩子说话。看图选择环节点击麦克风只提示当前操作，不打开提问弹窗。原有界面和学习进度沿用。

## 一次完整体验

1. **欢迎**：雪梨老师播报指定介绍语，随后进入主题选择，等待孩子选择。
2. **选主题**：爱干净开放；美味食物、快乐运动、动物朋友锁定。点击锁定内容有简短说明，老师引回今天开放的主题。
3. **选模块**：显示绘本、单词、视频、习题四个模块。本次开放单词，另外三个待解锁。可以点击单词卡或“开始学单词”，也可通过麦克风表达选择。
4. **随学随练**：依次学习 room、dirty、clean、tidy。每个词按“认识词卡 → 看图/理解 → 开口说词”推进；点喇叭听标准发音，点击雪梨老师形象提问，右下角麦克风只用于孩子跟读、回答。完成当前检查后才进入下一步。
5. **学习回顾与补练**：四个词共有八次理解/开口检查。实际回答生成记录和待补练项；同一词的理解与开口分别验证。一轮补练最多聚焦三个词，其余困难保留到下次，不删除原记录。全部通过时跳过补练。
6. **一次生活引导**：围绕爱干净问“除了整理房间，还知道哪些爱干净的事情？”气泡逐条出现；中文回答连接 wash hands，再验证英文表达，最多三轮后收束。同一主题在本次学习中只触发一次。
7. **单词模块总结 → 回学习地图**：总结只统计四个单词和模块内开口，地图将单词标记为完成。其他三个模块保持锁定。可重看学习回顾，不重做任务、不重复生成报告。
8. **今日收获 → 语音道别 → 首页**：今日总结合并单词任务和一次生活表达；道别播报与页面相同的明日计划。回首页后显示今日完成状态，允许查看记录，结束继续作答。

## 返回、继续与保存

- 顶部返回入口可以回学习地图或主题列表，当前任务与答案保留。
- 进行中的单词卡可以继续原位置；暂停在补练或生活问答时，主按钮说明要继续哪一项。
- 同一浏览器当天重新打开，先回主题首页，再继续保存的任务。正在等待的生活回答也会保存，回来后继续教师反馈。
- 声音与自动下载设置会保留。底部“重新演示”用于讲解人员重开一轮，已保存报告保留。
- 模块与今日报告自动保存在家长中心，默认发起下载。

## 讲解时推荐制造的三处困难

- room 的理解选“玩具”。
- dirty 的看图理解选“收拾好的房间”。
- clean 的开口识别结果选 `clen`。
- 其他检查通过。回顾应显示八次检查、五次正确、三次错误。
- 补练依次回答“房间”“玩具散落的房间”“clean”；生活问答回答“洗手”和 `wash hands`。
- 单词总结应有四个词通过、解决三处困难；今日总结额外包含生活表达。开口次数按实际提问、试读和回答累积。

## 总结口径

**今日计划 1/1 表示本次安排的单词任务完成。** 主题目录有四个模块，另外三个没有学习，不能计为完成。

单词模块的掌握数量和开口次数只来自模块内记录；生活问答计入今日总结。首次作答、补练和老师示范分别保存。老师示范既不计为孩子开口，也不把未通过项变成已掌握；同一词的两个验证任务必须都通过。

## 实现与验证边界

老师使用浏览器语音合成；首次可能需要点击老师启用。AI 回复、识别和评分使用本地规则模拟，麦克风打开演示输入区，不采集录音、不调用真实模型。评分核对识别文本，不评估真实口音。

进度和报告保存在当前浏览器，不发送到远程家长端。顶部商城等入口保留为辅助入口，学习记录与家长中心可查看本轮报告。

源码在仓库的 `demo/xueli-ai/src/`；运行 `python3 src/build.py` 可生成单文件 `index.html`。截图为 `previews/v6-*.png`。浏览器验证脚本位于 `verification/`，默认访问 8026 端口，可用 `DEMO_URL` 修改；需要当前云环境的 Playwright / Chromium。

具体功能对应和验证范围见 `需求对照与验收.md`、`验收结果.md`。
