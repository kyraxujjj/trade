# 最新要求与交互实现对照

本版以用户重新提供的全部原稿图和随后的逐项说明为准。原图约束视觉框架；页面内部的对话、输入、反馈、重试、语音与数据变化是实际 HTML 状态和事件。

| 用户说明 | 实现 |
| --- | --- |
| 首页由雪梨 IP 发声，说指定欢迎语 | 首次尝试自动 TTS；欢迎内容逐字采用指定话术；点击原图老师可重播，播放完成进入学习。浏览器禁止自动发声时保留欢迎页，等待原图老师或主按钮的一次点击 |
| 正常课程只展示原图形式的图片学习，换成爱干净 | 保留原课程画面外围 UI、老师、框架与按钮；修改插图、标题、词句；四句英语可朗读，麦克风支持基于当前句子的疑问和跟读 |
| 错误汇总按照原稿设计 | 单词、句子和练习统计三行结构原位保留；词汇换成 clean / room / dirty，句子用否定与肯定表达。示例记录与本次回答共同决定待复习项 |
| 普通补练沿用现有交互和设计，内容换成爱干净 | 图片、目标词句、具体问题、标准发音、再听、提示、反馈、星级均在原稿位置；支持正确、不清楚、漏 not、两次失败后的跟读降级；当前知识点完成才可继续 |
| 深度引导对话一条一条出现 | 原稿中的老师头像气泡先出现 → 等待孩子 → 孩子头像气泡出现 → 间隔后老师回复出现并播报 → 词组卡随后出现。相关、弱相关、明显跑题、表达不完整走不同分支。新增气泡单独动画，已有气泡不重复弹出 |
| 同一本绘本只进行一次深度引导 | 针对本次绘本进入一次引导，位于补练后、总结前；对话内可以多轮，但最大三轮，然后有效验证或示范跟读收束 |
| 模块 / 整次总结直接沿用原布局 | 原统计栏、左右反馈区、原装饰与鼓励区域保留，只在对应文本和数字位置更新学习状态；报告保存到本地家长中心，默认发起下载 |
| 离开 App 时直接给孩子语音 | 进入道别自动调用 TTS，内容读取剩余弱项；无遗留问题时回顾 room / clean。结束学习后禁用麦克风，不重新开始教学 |

## 学习数据与模拟范围

为直观展示错误汇总，本版起始载入七条示例记录：clean、room、完整否定句待补练，dirty、tidy、this、肯定句已掌握。正常图片课程的跟读、后续补练和生活表达验证可以改变结果。生活引导只新增一个表达 wash hands。

独立回答通过才更新为已掌握。提示后跟读保留待巩固，不用一段表扬话术代替验证。汇总统计不是对未展示课程行为的真实测量，报告和演示说明中都标明数据来源。

欢迎和道别调用浏览器 TTS；AI 语义、语音识别、发音评分与远程家长端为模拟。输入区是演示操作工具，不采集真实儿童录音。
