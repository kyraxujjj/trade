# V8 需求与交互对应

本次明确调整为“去掉锁定，自由选择学习内容”，同时移除截图中的强制次日道别流程。原课堂背景、IP 和主要框架沿用。

| 需求 | 实现 |
| --- | --- |
| 不限制每日学习量 | 取消 ended 学习阻断；不按日期重置或限制学习；允许立即开启新一轮 |
| 自由选择主题 | 四个主题卡都可进入，不显示待解锁 |
| 自由选择模块 | 每个主题下四个模块直接可进入，不要求前置模块 |
| 保留核心 AI 评练 | 爱干净单词保留八次检查、真实错题、对应补练、单次生活引导 |
| 其余入口能够体验 | 基础绘本共读、词卡听读与开口、情景动画、理解选择题 |
| 移除强制道别 | 本次总结后返回地图，无“必须明天再学”页面 |
| 自主选择休息 | 可选休息弹窗，之后随时返回继续，记录不清空 |
| 学过也能再学 | 新轮次保存独立报告，之前的记录保留 |
| 引导不重复 | 爱干净内容重练不再次询问同一生活问题；不复制上轮开口统计 |
| 入口职责 | 老师形象用于帮助，麦克风用于孩子开口 |
| 进度连续 | 各主题/模块独立进度，离开与刷新后可继续 |
| 旧版本兼容 | 已完成、已结束或前一日期的草稿可继续，不沿用每日锁定 |

## 统计规则

“本次学习总结”只统计当前这轮爱干净单词与该轮实际发生的生活表达，不代表一天只能学一个模块，也不把其他模块算作完成。

基础模块独立保存实际浏览页、回答、开口与轮次。共读和观看不等同于掌握；练习记录保留错误，重练不覆盖原报告。

## 演示范围

核心完整 AI 互动为爱干净单词。其他主题/模块用基础交互补齐自由选择路线；视频入口为本地 HTML 情景动画示意。识别、评分与 AI 回复均为规则模拟，教师语音使用浏览器合成。
