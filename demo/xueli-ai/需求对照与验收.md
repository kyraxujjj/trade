# V6 产品流程与交互对应

原始文档明确四个模块为绘本、单词、视频、习题。最新要求在八个 AI 功能场景之间补齐 App 的选择、返回、继续、完成状态与自然衔接。本次只开放爱干净主题下的单词模块，目录中其他内容锁定。

## 课程与任务范围

- 主题：爱干净。
- 本次今日计划：单词模块一项；不把另外三个模块计为完成。
- 目标词：room、dirty、clean、tidy，各有理解和开口两种检查。
- 有限拓展：同一主题只增加一次生活引导和一个表达 wash hands。
- AI 始终读取所选主题、所选模块、当前词、任务步骤、原始错误及本轮补练状态。

| 场景 | 孩子的操作 | AI 与后续衔接 |
| --- | --- | --- |
| 欢迎 | 听介绍、点击老师或开始按钮 | 进入主题选择，等待真实选择 |
| 主题选择 | 点爱干净，或说想学爱干净 | 老师介绍所选主题；锁定内容有说明，保持原位置 |
| 四模块地图 | 点单词、说想学单词、返回主题 | 开始今日单词计划；其余三项保持锁定 |
| 词卡认识 | 看图、听词、问意思、试读 | 只解释当前词；推进到理解检查 |
| 理解检查 | 选择词义或对应图片 | 保存实际答案；再进行开口验证 |
| 开口验证 | 用模拟识别或文字回答词语 | 保存实际结果；进入下一个词卡，直到四个词完成 |
| 学习回顾 | 看真实统计、原答案与原因 | 优先选最多三个词补强；全通过则进入生活问答 |
| 针对性补练 | 重新理解或重新说词；听标准、求提示 | 必须验证同一难点；最多两次，仍未通过则老师示范并保留待巩固 |
| 生活引导 | 中文习惯回答，再试英文 | 逐条气泡，最多三轮；暂停后继续原回答，不重复引导 |
| 单词模块总结 | 看四个词的掌握与模块内开口 | 返回地图，单词标记完成；重看仅查看原报告 |
| 完成后的地图 | 查看单词回顾或今日收获 | 由孩子决定进入今日总结，其他模块仍未计为完成 |
| 今日总结 | 看整体收获、完成今日学习 | 合并单词与生活表达，生成今日报告 |
| 道别与首页 | 听下一次计划，说再见或点击结束 | 结束继续作答；首页呈现今日完成，可查看记录 |

## 连贯性规则

1. 欢迎结束只进入主题列表，不绕过主题和模块选择。
2. 单词模块不再用绘本句子课程冒充；词卡、题目、原答案、补练及总结使用相同词 ID。
3. 每个词按认识、理解、开口推进，提交之前不能跳到下一步。
4. 返回只切换位置，不清空学习结果；当天重新打开可继续原任务，声音与自动下载偏好保留。
5. 生活回答及尚未展示的教师反馈也会保存；重新进入续接，不重复记录主题问题。
6. 同一词的理解通过不能覆盖开口失败，反之亦然；老师示范不算独立通过。
7. 所有原始错误完整保存；一轮最多聚焦三个词，未安排补练的错误也进入待巩固和明日计划。
8. 单词报告只统计模块内数据，今日报告才合并生活问答；两份报告保存在本地家长中心。
9. 今日 1/1 只指安排的单词任务，不意味着绘本、视频、习题已经完成。
10. 模块完成后允许回顾；不会重新开始学习或重复生成报告。道别后不再计入回答。
