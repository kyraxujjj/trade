# 产品功能与交互对应 V5

用户提供的八张 UI 图确定视觉结构，并非只能切换八张图的幻灯片。课程、习题、补练和对话均有自己的内部状态；后续结论必须能追溯前面的实际作答。

| 功能场景 | 前置条件与操作 | 结果与后续指代 |
| --- | --- | --- |
| 首页欢迎 | 自动尝试用户指定欢迎语；点击可以启用声音 | 语音结束进入爱干净绘本 |
| 正常课程 | 四句课文、中文释义、当前句提问与试读 | 所有正式题目绑定对应教学句子 |
| 课堂练习 | 七道词义、看图、完整表达题；提交后继续 | 生成原始作答记录，无预置错误 |
| 错误汇总 | 七题完成后，统计首次结果 | 展示实际错误；卡片可查看原答案与原因；全对跳过补练 |
| 针对性补练 | 队列包含所有实际错题，不截断 | 验证同一题与同一难点；两次未通过后老师示范、保留待巩固 |
| 深度引导 | 练习和补练结束后，同一本只触发一次 | 气泡依次出现；中文习惯回答连接 wash hands；英文验证或三轮后收束 |
| 模块总结 | 完成生活表达后生成 | 展示实际掌握、开口、错题解决数与剩余困难 |
| 今日总结 | 完成一册示意绘本，1/1 | 汇总同一轮数据，报告保留原始作答和补练对应关系 |
| 离开道别 | 进入后自动播报 | 语音与页面使用相同明日计划；待巩固优先，全对则安排简短回顾 |

## 统计口径

- 首次正确 / 错误：七条正式题目的原始作答，后续复习不会改写。
- 已解决错误：原错题中出现一次补练通过的题目数。
- 已掌握知识点：对应所有正式验证均通过；失败题可由同题补练通过补齐。
- 待巩固：仍存在未通过的题目，或生活表达仅完成老师带练。
- 开口：孩子实际模拟提问、试读、句子作答、口头补练及生活回答；不含选择点击与教师播报。
- 下一次计划：先取本轮剩余薄弱点，最多两个；不足时补入 room / clean 的简短回顾。

正式习题、原始错题、复习结果、总结和计划共用一个状态源；报告保存快照。结束后的入口不会继续累加学习记录。重置会清除当前轮状态，保留已经保存的历史报告。
