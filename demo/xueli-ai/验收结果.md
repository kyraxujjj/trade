# V5 验收结果

日期：2026-10-14。Chromium + Playwright 在云环境中验证生成的单文件 HTML；学习路线通过页面按钮、选择与模拟识别输入完成，未注入预置作答结果。

## 主路线：真实作答 → 三道错题 → 同题补练 → 一次生活引导

- 初始没有错题或已掌握结果。
- 七道题实际提交：第 1 题 room 选“玩具”；第 4 题 not clean 选“收拾好的房间”；第 7 题跟读漏掉 not。其余四题通过。
- 汇总显示七题、正确四题、错误三题；清单与报告保留孩子原答案。
- room 补练通过模拟语音输入“我还不知道”失败一次，原输入完整保存；之后选择“房间”通过。
- 第 4 题重新理解“不干净”，选择“玩具散落的房间”通过；第 7 题仍待巩固，未被前一题通过抹掉。
- 第 7 题重新提交完整句子通过，统计解决三道错题。
- 生活引导只触发一次。确定性时钟验证：老师提问 → 孩子气泡先出现 → 800 毫秒后教师反馈 → 播报结束后词组卡出现。
- 回答“洗手”并提交 wash hands 后：掌握七个知识点、解决三道错题、模拟孩子开口七次。普通选择点击、听老师发声、老师带练不计开口。
- 两份报告实际触发下载；报告保存首次错误与对应补练。家长中心显示两份记录。
- 道别自动触发，播报结束后可完成学习；结束后麦克风禁用。

## 验证边界

语音验收用替代的合成事件核对文本、触发时机及回调，不验证设备实际音色或音量。当前云环境浏览器策略禁止直接访问 file://，因此断网验证使用交付 HTML 的原文加载；用户版本图片和脚本均已内嵌。

AI 回复、识别与评分均使用本地演示规则。句子核对识别文本，不评估真实发音。家长中心使用当前浏览器本地存储，不发送远程消息。
