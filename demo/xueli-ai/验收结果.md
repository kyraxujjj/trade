# V7 App 交互验收结果

日期：2026-10-14。使用 Chromium / Playwright 验证生成的单文件 HTML。学习记录通过实际页面选择与模拟语音输入产生，未注入预置错题。

## 点击入口调整

- 词卡页点击麦克风直接打开孩子试读输入，不显示“是什么意思”等课程提问选项。
- 点击雪梨老师形象打开原有提问弹窗；提问后继续当前学习，原题和答案保持。
- 看图理解环节点击麦克风仅提示先选择答案，点击老师仍能打开当前 dirty 词的提问弹窗。
- 原有开口检查、口头补练和生活问答继续通过麦克风提交，完整主流程通过，未产生 JavaScript 异常。

## 主路线

欢迎语播报 → 主题选择 → 点击爱干净 → 四模块地图 → 选择单词 → 四个词随学随练 → 实际学习回顾 → 针对性补练 → 一次生活引导 → 单词总结 → 完成后的学习地图 → 今日总结 → 自动道别 → 完成状态的首页。

- 欢迎结束进入主题列表，等待用户选择；三个其他主题锁定，点击仅说明，不进入课程。
- 模块目录为绘本、单词、视频、习题，只有单词开放；选择时写入真实主题和模块上下文。
- 每个词都有认识、理解、开口三个步骤。提交前下一步不可用，当前词问题不会自动生成答题记录。
- 故意制造三处困难：room 理解选“玩具”；dirty 对应图片选整洁房间；clean 开口识别为 clen。其余五次检查通过。
- 学习回顾为八次检查、五次正确、三次错误；原答案和原因可查看。
- 中途回地图再继续，保持未完成的 room 开口步骤，不重做、不重复记答案。
- 补练通过对应的词义、图义和开口任务，解决三处困难。
- 确定性时钟验证生活气泡逐条出现：孩子回答先出现；800 毫秒后教师反馈；播报结束后词组卡出现。反馈未结束时总结按钮不可用。
- 主测试包含一次课程问题、四次开口检查和一次口头补练：单词报告掌握四个词、模块内开口六次；今日报告合并两次生活回答，掌握五项、开口八次。
- 总结后返回地图，单词显示完成，其他三项仍锁定。重看单词回顾不重做生活引导、不重复生成报告。
- 今日计划完成项仅为 words，1/1；不会把绘本、视频、习题计为完成。
- 两份报告实际触发下载，保存在家长中心；内容保留选择路径、原答案与补练对应关系。
- 道别自动播报；完成后可以回首页，今日完成状态保留，继续作答禁用。

## 验证边界

语音验收使用替代合成事件验证文本、触发和回调，不验证具体设备音色与音量。当前云浏览器禁止直接访问 file://；断网验证加载交付 HTML 原文，检查图片和脚本自包含。

识别、AI 回复与评分为本地规则模拟，不能评估真实口音或任意自然语言语义。进度与报告使用当前浏览器本地存储，不发送远程消息。
