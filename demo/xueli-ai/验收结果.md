# V8 交互验收结果

日期：2026-10-15。使用 Chromium / Playwright 验证生成的单文件 HTML。

## 核心路线

欢迎 → 自由选择主题 → 四模块地图 → 爱干净单词学习 → 八次真实检查 → 三处真实困难 → 对应补练 → 一次逐条生活对话 → 单词总结 → 本次收获 → 返回地图或自主休息 → 立即重练。

- 四个主题与四个模块不再显示锁定，不存在每日任务配额。
- 老师形象打开提问，麦克风用于孩子试读与回答。
- 原课程检查、补练对应、逐条对话、模块/本轮统计和实际报告下载保持。
- 重练实际完成新一轮八次检查，原报告内容保留，新轮开口数独立统计。
- 重练跳过已经完成的同内容生活引导，不重复制造开口记录。
- 完成或休息后可立即继续学习，不跳到强制道别页。
- 旧“已结束”草稿与前一日期的草稿恢复后，也不会阻止继续。

## 自由选择与基础内容

- 遍历四主题、四模块的全部入口，核心单词外的十五条路线均可进入，返回地图保留进度。
- 绘本真实翻页、模拟跟读、返回和刷新后继续原位置；浏览只记录参与。
- 理解题实际提交一个错误与三个正确答案，独立报告对应实际结果。
- 基础词卡必须通过孩子开口输入才能推进，四个词结果与四次模拟开口独立保存。
- 情景动画的语音、字幕、播放、暂停和继续可交互；打开老师帮助暂停播放。
- 学完一个模块，可立即选另一个模块或重练；各轮报告保留，未学习内容不算完成。
