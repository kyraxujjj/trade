# MVP报告与原页陪练核对

## 用户报告应包含

1. 今日课程与学习内容：绘本、任务完成情况、具体词汇和重点句。不能只写AI帮助次数。
2. 已经做得不错：引用原学习记录中可独立完成的词句；本例7个动作词独立完成，writing词尾需帮助。
3. 还需复习：具体到词、句和错误位置。writing针对-ing词尾；He is writing.针对漏is和整句完整度；方案3将听懂选图与独立口语分开。
4. 可执行建议与入口：复习这个词/这句话，携带lesson/module/item标识定位练习；完成后返回报告更新结果。仅播放标准音不能算完成；提示后结果不能覆盖首次结果。

## 方案1与方案2的边界

| 比较点 | 方案1 | 方案2 |
| --- | --- | --- |
| 介入时机 | 拼读/跟读模块结束后 | 当前词/句第一次卡住时 |
| 用户位置 | 进入独立专项带练 | 保留原词卡/原句页 |
| 反复尝试 | 独立带练页内再试 | 原麦克风原位再试，最多两轮 |
| 带练后 | 再评估反馈→模块小结 | 原页反馈→继续下一题，整组结束才小结 |
| Demo实现 | A1/A2与A4/A5是独立练习及反馈状态 | B2/B5合并为B1/B4内的状态，不再单独翻页 |

## 流程图的正向分支

- 方案1/3：原模块达标→绿色箭头直接进入该模块小结；未达标才进入带练/情境巩固。无论帮助后达标、仍需巩固或跳过，都能继续。
- 方案2：当前题读对→绿色箭头指向原页继续下一题；整模块完成后才进入小结。当前题需帮助→原页提示→原位再读→原页反馈，可在原页再练一轮。
- 六模块完成→用户学习报告→按具体薄弱点复习→返回报告查看进步。Memory保存属于后台，Planner是后续能力。

## 数据和上线接入

当前HTML以示例课程演示用户界面；正式需从学习记录读取：lesson_id、module_id、item_id、content/resource_id、首次结果/错误跨度、是否用了帮助、每次重试结果、独立完成结果、复习来源及复习后结果。报告文案只引用存在的记录；未评测的表达不得因为选图正确就算掌握。

当前复习入口在报告内打开对应学习面板，保留具体词/句和lesson/module/item标识。正式App应复用原课程对应学习组件，并回写本次复习结果。语音录音、真实识别与评测、服务端持久化仍需接入，不能将本地预设评分当作生产评测。
