# 方案1与流程图核对

原课程固定六模块不变。这里的“全部读完”按流程图指当前拼读模块的全部词、当前跟读模块的全部句子。

| 节点 | 触发与内容 | 下一站 |
| --- | --- | --- |
| A1 | 原拼读8个词全部首次作答完成，展示全组结果并汇总错词 | 有弱项到A2，全对或暂时跳过到A3 |
| A2 | 独立集中带练 riding、writing；逐项示范、试读和同页反馈；已经读好的词不进入 | 仍有弱项留在本页练下一项，整份清单结束到A3 |
| A3 | 拼读模块小结，区分能自己读、集中练后读清楚、仍需复习 | 先继续原词句跟读 |
| A4 | 原跟读3句话全部首次作答完成，汇总2个弱句 | 有弱项到A5，全对或暂时跳过到A6 |
| A5 | 独立集中带练两个弱句，逐项反馈 | 整份清单结束到A6 |
| A6 | 跟读模块小结 | 原趣味动画、拓展阅读 |
| A7 | 整课今日报告：8词、3句、掌握情况、4处具体复习入口 | 定位对应词句复习，再回报告 |

每项最多试读2次；未通过或跳过保留待复习，不强制反复。听示范只记帮助，不改变掌握状态。集中带练后的读清楚与后续独立复习读清楚分开，首次结果保留。方案1示例首次为6/8词和1/3句可独立读；报告统计逐项计算，不使用固定的7/8基线。

方案2保留原词卡与原跟读页的即时帮助，方案3保留情境理解与表达分别记录。共用问答独立于三套主流程。
