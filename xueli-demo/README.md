## 方案1的顺序

按模块先全部读完：8个词的原题全部完成后，A1展示全组首次结果，将 riding、writing 两个薄弱项组成清单；A2是独立的集中带练页，按清单依次练习和反馈。整份清单结束后才到A3拼读小结，读好的6个词不重练。

继续原词句跟读，3句话全部读完后，A4汇总两个弱句，A5集中带练，最后到A6跟读小结。原趣味动画、拓展阅读仍保留；整课结束到A7学习报告。

全组首次作答全对时直接进入对应模块小结，不触发集中带练。跳过、最多两次仍未读清楚的内容继续保留复习建议，听示范不计作读好。报告列出本课8个词、3句话以及逐项复习入口；复习记录与首次记录分开。

方案2则在当前原题就即时给提示、重复练习和反馈，词图、麦克风、画廊计数和页面DOM保持不变。

## 演示边界

课程与学习记录为示例；原课程普通学习页不单独重画，画廊只呈现AI触点和必要的全组结果上下文。语音、识别和评分使用预设结果，正式上线需接入真实课程记录、教研原音与评测服务。全部素材、样式与脚本内嵌在HTML中。
