## 文档基准与保留内容

基于用户指定链接对应的033d63b提交原始HTML，补齐截图中的11项AI能力总览：随身助教、错误救援、模块小结、综合学习总结、Learning Memory、记忆回访、阶段复习／补弱、补习模式、挑战模式、学习换挡和Planner。人群、动作、什么时候不做、阶段标签均按截图保留。

此前已确认的三套方案修正继续保留：方案1先整组读完再集中练弱项，方案2在同一原页连续陪练，三套报告总结具体词句与复习建议。最初架构的完整“小梨统一联动入口”章节及交互也恢复保留。

## 两条路径严格分开

**AI记忆回访**只面向高正确率、表面已掌握且无明显薄弱点的孩子。3天后先速答与无提示验证，长期再次验证并做迁移；多次稳定后停止额外回访。新发现的具体薄弱项交给阶段复习，不继续沿“已掌握”路径测试。

**AI阶段复习／补弱**面向已有薄弱点的孩子。完成2–4个Lesson或间隔一段时间后：轻量回顾→只对仍不稳的内容专项练→必要时独立再测→报告。近期高正确率且无薄弱点的孩子不参加，不固定周测。已经能独立读的跳过重复带练，连续低收益练习到上限即停止。

## 体验方式

记忆回访画廊外将“日期”切到第3天，从M1开始。独立全对后保存，才生成下一次长期回访；切到第17天继续，再完成M4换图迁移后，M5会显示稳定停止。示例长期为首次通过后再间隔14天，稳定次数为2次；这些是待教研确认的可配置提案。

可将“独立作答”或“迁移”切成未通过，核对只交接失败项到S2。阶段复习默认已有3处薄弱点，可直接从S1开始；画廊外可核对排除条件、2／3／4课与时间触发、轻量回顾直接读对、练后仍未过和必要再测等分支。

## 页面与说明

记忆回访M1–M5，阶段复习S1–S6，共新增11张原生交互页面。每页附页面定位、用户场景、触发与交互、按钮／AI联动、建议回传数据和下游用途六栏说明。流程写明答对、需要帮助、未到期、排除、停止及跨功能交接去向。

## 验证与边界

两类人群排除、3天与长期调度、无提示回忆、首次结果保留、稳定且迁移成功后停止、仅薄弱项交接、2–4课或时间触发、跳过多余带练、两次低收益停止、必要再测及刷新续做已验证。原三方案交互与18张页面回归通过，总计29张产品页面。

课程和学习记录为示例，语音、识别、评分使用预设结果，状态保存在当前浏览器。正式服务需接入真实课程、教研音频、语音评测、服务端账户与调度。总览中“待敲定”“后续”仍代表产品阶段，做出Demo不等于线上功能已经上线。
