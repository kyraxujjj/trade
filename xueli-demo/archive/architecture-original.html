一期最终交付定义：
孩子完成固定六模块学习后，系统能知道“哪里会 / 哪里不会”； 在单词拼读和词句跟读两个节点，根据结果判断是否自动发起受控 AI 二次带练； 每个关键模块结束后形成模块小结；右下角小梨能读取当前学习上下文进行问答，并与带练、模块小结、最终总结联动； 六模块结束后形成一致的 AI 综合总结，并将掌握状态、薄弱点、AI 干预结果写入长期 Learning Memory。

一期课程规划仍固定，但已经为后续 Planner Agent 接管“下一步怎么学”准备好数据基础。

适合注意力易被打断、仅在单词或句子上短暂卡住的孩子。AI嵌入白色原页；数据重点是提示方式是否有效。

方案3｜绘本情境闯关

适合需要兴趣和情境应用来巩固知识的孩子。新增黄色情境小关；数据重点是基础知识能否在绘本情境中应用。

4. 右下角“小梨”怎么从被动按钮变成 AI 联动入口

不是单独做“聊天”，而是作为 Tutor Agent 的统一前台入口。

推荐机制：同一个小梨，随学习状态变化

默认状态下，它是“随时问我”；出现错误时，它自动变成“有一个地方需要再练”；六模块完成后，它变成“我帮你总结好了”。用户不需要理解背后有几个 Agent。

关键设计：系统该主动时主动，用户想主动问时也能问。这样 AI 使用率不再完全依赖孩子“想不想点按钮”。

对话功能完全可以和其他 AI 能力联动：小梨打开后先读取当前学习上下文。如果系统刚检测到错误，则直接进入带练；如果没有任务，则进入自由问答；如果六模块已结束，则优先解释本次学习总结。

5. 一期边界：做什么 / 不做什么

边界越明确，一个月越可控。

★ 一期必须完成

  • 单词拼读结果 → 判断是否触发二次练习
  • 词句跟读结果 → 判断是否触发二次练习
  • 拼读模块小结 + 跟读模块小结（无论是否触发二次练习都要输出）
  • 错误自动触发小梨提醒
  • 针对错误的二次带练
  • 课程上下文内 AI 问答
  • 六模块完成后的 AI 综合总结
  • Learning Memory 写回
  • 教研资源最小可调用能力
  • 全链路数据记录，为后续 Planner 做准备

一期暂不做

  • AI 自由重排六模块顺序
  • 完全自动决定下一本绘本
  • 复杂长期性格画像
  • 无限轮开放式儿童聊天
  • 自动生成大量新课程内容
  • 复杂多 Agent 自主协作编排
