记录原题是否掌握、情境小关题型、图片 / 语音选择结果、是否需要提示与当前掌握状态。
→
二期 Planner Agent
根据原题和情境任务的差异，判断应该巩固、继续新绘本还是尝试更高难度。
核心用户需求：有些孩子不喜欢“刚才错了再做一次”，但愿意在原绘本角色和图片里参与短挑战。小关限定当前绘本的已审核素材，用“听音找图 / 图词匹配 / 听句选图 / 跟读一句”等低阅读负担动作，约20–60秒；不要求孩子独立创作英文故事，也不篡改既定绘本文本。
可记录 / 上传的学习数据：初始拼读/跟读结果、情境关目标知识点、题型、正确率、提示次数、完成时长与原题/迁移表现差异；学习报告展示“基础掌握 / 情境应用 / 待巩固”。
方案1｜集中式二次带练

适合已经明确出现错误、愿意集中补练的孩子。单独插入黄色AI带练节点；数据重点是带练前后提升。

方案2｜原页实时教学

适合注意力易被打断、仅在单词或句子上短暂卡住的孩子。AI嵌入白色原页；数据重点是提示方式是否有效。

方案3｜绘本情境闯关

适合需要兴趣和情境应用来巩固知识的孩子。新增黄色情境小关；数据重点是基础知识能否在绘本情境中应用。

4. 右下角“小梨”怎么从被动按钮变成 AI 联动入口

不是单独做“聊天”，而是作为 Tutor Agent 的统一前台入口。

推荐机制：同一个小梨，随学习状态变化

默认状态下，它是“随时问我”；出现错误时，它自动变成“有一个地方需要再练”；六模块完成后，它变成“我帮你总结好了”。用户不需要理解背后有几个 Agent。

关键设计：系统该主动时主动，用户想主动问时也能问。这样 AI 使用率不再完全依赖孩子“想不想点按钮”。

对话功能完全可以和其他 AI 能力联动：小梨打开后先读取当前学习上下文。如果系统刚检测到错误，则直接进入带练；如果没有任务，则进入自由问答；如果六模块已结束，则优先解释本次学习总结。

5. 一期边界：做什么 / 不做什么

边界越明确，一个月越可控。

★ 一期必须完成

  • 单词拼读结果 → 判断是否触发二次练习
  • 词句跟读结果 → 判断是否触发二次练习
  • 拼读模块小结 + 跟读模块小结（无论是否触发二次练习都要输出）
  • 错误自动触发小梨提醒
  • 针对错误的二次带练
  • 课程上下文内 AI 问答
  • 六模块完成后的 AI 综合总结
  • Learning Memory 写回
  • 教研资源最小可调用能力
  • 全链路数据记录，为后续 Planner 做准备

一期暂不做

  • 完全自动决定下一本绘本
  • 复杂长期性格画像
